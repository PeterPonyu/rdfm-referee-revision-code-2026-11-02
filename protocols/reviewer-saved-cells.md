# Reviewer-derived descriptions from fixed saved outputs

These are **post hoc descriptive checks** of outcomes already visible to the author and reviewers. They are not prospective tests or independently sampled replications. This protocol freezes the transcription, joins, denominators and display formatting before the candidate macro files are generated; it does not claim that the numerical outcomes were unseen.

- A: in the recorded FD004, primary-role, capped temporal-model array, select alpha `0.10` and `inverse_lifetime`; count engines with at least one empty cycle and sum empty and total cycles. Preserve the original 82-engine event and its coverage; this is not a fleet interval.
- B: from the saved two-orientation oracle aggregate at coverage `0.9`, subtract APS mean size from APS-hull mean size. This is a difference of separately oracle-matched means, not the cost of closing a particular set's gaps at one threshold. Use only aggregate JSON and output no donor/spot records.
- C: in the saved 20-allocation by 19-site fold table, pair the record-weighted and site-balanced rows by allocation and site. Count greater/equal/lower thresholds and held-site coverage. These reused sites are descriptive, and the comparison changes both score weights and infinity mass.
- R: count agreement of the two saved logistic restorer choices over the 15 recorded pipeline/noise cells. Separately transcribe four rules' already computed aggregate low-resolution logistic absolute accuracy, introduced-harm fraction and helpful-change counts from the saved metric summary. Preserve all four common-denominator decisions. Selection agreement is descriptive, not a new selector efficacy experiment.

Inputs and exact SHA-256 are embedded in the script and must match Git `HEAD` and the previously authenticated files. The script is committed before execution on a separate local evidence branch rooted at the current HEAD; it verifies the supplied commit's script and protocol blobs, the branch ancestry, and all input hashes. It writes only new candidate macro files and a new JSON ledger, with source selectors, full precision, displayed rounding, script/commit/input/output hashes and seed `null` (the calculation is deterministic). The script must refuse unknown or repeated flags, changed input, absent or duplicate row selectors, or existing output files. Its synthetic self-test covers pairing, duplicate/missing rows and wrong hashes.

The outcome was previously observed in the 2 November simulated reviews and coordinator checks. No result here may be called a prospectively confirmed headline or a population guarantee. No training, raw patient/spot data access, remote compute or download is involved.
